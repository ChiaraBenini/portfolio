Reinforcement Learning – FrozenLake

github.com/ChiaraBenini/reinforcement-learning-frozenlake

Overview

This project implements multiple reinforcement learning algorithms to solve the FrozenLake environment from Gymnasium. The agent must navigate across a frozen lake from start to goal while avoiding holes, learning optimal policies through trial and error.

Key Implementations

  • Dynamic Programming - Policy Iteration and Value Iteration for solving MDPs with full environment knowledge
  • Monte Carlo Methods - First-visit and every-visit MC prediction with exploring starts
  • Temporal Difference Learning - SARSA (on-policy) and Q-Learning (off-policy) implementations
  • Performance Comparison - Analysis of convergence rates across different algorithms

Technical Details

The FrozenLake environment (4x4 and 8x8 variants) presents a classic challenge in reinforcement learning: sparse rewards, stochastic transitions (slippery ice), and a clear goal condition. Key implementation challenges included:

  • Handling the environment's non-deterministic dynamics (33% chance of slipping)
  • Implementing proper exploration-exploitation trade-offs
  • Tracking convergence metrics across multiple episodes
  • Visualizing learned policies and value functions

Results

Q-Learning achieved the most stable convergence, reaching ~80% success rate on the 4x4 map after 2000 episodes. The dynamic programming methods quickly found optimal policies when the transition dynamics were known, while Monte Carlo methods required more episodes but effectively learned without a model.

Key Takeaways

  • Model-based methods (DP) converge faster but require environment dynamics knowledge
  • Q-Learning's off-policy nature makes it more sample-efficient than on-policy SARSA
  • Visualizing value iteration convergence helps debug agent learning progress
  • The stochastic environment makes deterministic policies less reliable
